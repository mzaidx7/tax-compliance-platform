# TBT Compliance Platform Design System

## Direction

The platform is a dark operational workbench. Firm identity is persistent and unmistakable, while member state and security actions read like a controlled register rather than a generic dashboard. It inherits the TBT ink, charcoal, restrained gold and silver identity without the atmospheric motion used on the public website.

## Operating Scene

Accounting and tax professionals use the platform for sustained desktop work in normal office lighting. The interface is dark to match the TBT identity, but content surfaces are matte and high-contrast rather than glossy. Mobile layouts support review and essential actions without pretending dense operational work is phone-first.

## Typography

- Instrument Sans is the current bundled interface and reading family.
- Inter remains the approved future option when platform font packaging is reviewed.
- Lato 900 may be used sparingly for the product name or major page title once approved assets are wired.
- Headings use weight and scale for hierarchy, never gradient text or excessive tracking.
- Operational labels use sentence case.

## Colour and Surfaces

- Canvas: near-black ink.
- Navigation: deep charcoal.
- Primary reading: cool silver.
- Secondary reading: zinc grey with accessible contrast.
- Gold marks current firm, focus, primary actions and selected navigation.
- Green, amber and red are reserved for real lifecycle state.
- Use one border or one shadow per surface, not both.

## Layout

- A persistent sidebar owns product navigation and active-firm context.
- The content well uses a maximum width suited to dense tables and forms.
- Members are displayed as a continuous register with aligned columns, not a grid of profile cards.
- Invitation creation sits beside its roster context on wide screens and above it on narrow screens.
- Empty states explain the next safe action.

## Components

- Firm switcher: compact context control showing firm name and current role.
- Status badge: sentence-case lifecycle value with restrained semantic colour.
- Primary action: gold fill with dark text and visible focus treatment.
- Destructive actions: explicit text labels and confirmation where required.
- Forms: labels remain visible; validation names the problem and recovery.

## Motion

Use one restrained transition when firm context changes. All data and controls remain visible without animation. Respect reduced-motion preferences.

## Accessibility

- Target WCAG AA contrast.
- Preserve visible keyboard focus for every action.
- Use semantic tables on wide screens and labelled stacked rows on small screens.
- Keep touch targets at least 44 pixels where controls are isolated.
- Never use colour as the only indication of role or status.

## Content Voice

Use concise operational language. Name the firm, action, state and recovery path. Avoid claims of regulatory approval, guaranteed compliance or automated filing.
